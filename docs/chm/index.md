- [User - Authentication](/chm/user/authentication) — obtain the bearer token used by protected endpoints.

The documentation is being rebuilt one record type at a time; sections appear here as they complete review. See [Record Types](/chm/record-types) for the documented set, [Realms](/chm/realms) for request routing, and [Custom Types](/chm/custom-types) for the field types used in the tables.
